# 南萤杯国际华语辩论赛计时器

## 快速开始

* 直接双击 `index.html`，在现代浏览器中打开即可使用。
* 右上角“选择场次”可在 A-H 组及淘汰赛场次中切换，计时器会自动显示对应学校、校徽和辩题。
* 右上角“修改数据”可以在网页中修改学校名称、校徽文件名和每场辩题，也可以新增十六强、八强、半决赛、决赛场次。
* 推荐使用 Chrome、Edge、Firefox 等现代浏览器，不支持 IE9 及以下版本。

## 目录结构

```text
.
├── index.html                  # 计时器主页面
├── data.js                     # 赛程数据（学校、校徽、辩题、赞助商）
├── assets/
│   ├── audio/                  # 提示音
│   ├── fonts/                  # 计时器像素字体
│   ├── images/                 # 页面图片与待定校徽占位图
│   ├── js/                     # 业务脚本（SeaJS 模块）
│   ├── logo/                   # 学校校徽
│   ├── styles/                 # 业务样式
│   └── vendor/                 # 第三方库
└── docs/
    └── screenshots/            # 文档截图
```

## 修改赛程数据

所有赛程数据集中在根目录的 `data.js`，可以直接用记事本或 VS Code 编辑：

* `event`：赛事名称、阶段和赞助商。
* `teams`：参赛位编号、学校名称、校徽文件名；联队使用 `logos` 数组填写两个校徽。
* `groups`：A-H 组，每组 3 队，按 `1v2`、`2v3`、`3v1` 进行三场比赛。
* `groups[].topic`：辩题；正方与反方之间用 `/` 分隔。
* `groups[].proTopic` / `groups[].conTopic`：正方、反方完整辩题。
* `matches[].date` / `matches[].time`：该场日期与时间。
* `extraMatches`：十六强、八强、半决赛、决赛等额外场次。

校徽图片放在 `assets/logo/`，在 `teams[].logo` 或 `teams[].logos` 中填写文件名即可。没有校徽时留空，页面会显示通用校徽占位图；联队会预留两个校徽位置。

也可以点击页面右上角“修改数据”：

* “应用修改”：立即更新当前页面，并保存在浏览器本地。
* “保存到文件”：Chrome / Edge 会打开保存对话框，选择覆盖根目录的 `data.js` 即可长期生效。
* “下载数据文件”：其他浏览器可下载 `data.js`，再手动替换根目录的 `data.js`。
* “新增场次”：填写阶段、双方学校和辩题，即可添加十六强、八强、半决赛或决赛场次；从列表选择学校后会自动填充校徽文件名，勾选“联队”可填写两个校徽，已添加的额外场次可修改辩题或删除。
* 参赛学校表格中也可以勾选“联队”，为联队选择两个校徽。
* “重置为文件数据”：丢弃浏览器内的修改，恢复为数据文件内容。

## 命名约定

* 目录与文件名统一使用小写；多单词使用 kebab-case，例如 `jquery-onepage-scroll`。
* 业务脚本放在 `assets/js`，第三方库放在 `assets/vendor`，二者不混放。
* 媒体资源按类型分目录：`images`、`audio`、`fonts`、`logo`。

## 赛制流程

辩论赛共分为 7 个回合：

* 正方一辩陈词（3 分钟）
* 反方四辩质询正方一辩（2 分 30 秒）
* 反方一辩陈词（3 分钟）
* 正方四辩质询反方一辩（2 分 30 秒）
* 正方二辩陈词（3 分钟）
* 反方三辩质询正方二辩（2 分 30 秒）
* 反方二辩陈词（3 分钟）
* 正方三辩质询反方二辩（2 分 30 秒）
* 正方三辩质询小结（3 分钟）
* 反方三辩质询小结（3 分钟）
* 自由辩论（8 分钟）
* 反方四辩总结陈词（4 分钟）
* 正方四辩总结陈词（4 分钟）

## 功能

* A-H 组小组赛赛程选择
* 十六强、八强、半决赛、决赛等额外场次
* 自动渲染学校、校徽与双方辩题
* 网页内编辑赛程数据、新增场次并导出
* 4 种提示声音
* 3 种计时类型
* 上下切换、多页面共存
